# Security policy

## Supported version

Security fixes are applied to the current default branch and included in the next release.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Include the affected version, platform, reproduction steps, impact, and any suggested fix. Avoid opening a public issue until a fix is available.

Archive extraction is security-sensitive. Reports involving path traversal, unsafe links, overwrite behavior, malformed archives, or decompression resource use are especially useful.
